# 動画字幕生成・リアルタイム翻訳ツール

動画ファイルに日本語字幕を自動生成したり、マイクの音声をリアルタイムで翻訳するツールです。

## このツールでできること

| 機能 | 説明 |
|---|---|
| **動画に字幕を付ける** | 英語の動画を自動で文字起こし・翻訳し、日本語字幕付き動画と SRT ファイルを生成します |
| **マイクをリアルタイム翻訳** | マイクに向かって話すと、リアルタイムで文字起こし・翻訳されます |
| **音声ファイルを翻訳** | WAV・MP3 などの音声ファイルをアップロードして翻訳できます |
| **辞書を作る** | 専門用語の訳語を画面上で登録できます。講義資料や翻訳結果から用語の候補も提案します |

## 必要なもの

### APIキー（2つ）

このツールは外部の AI サービスを使っています。利用には各サービスの API キーが必要です。

> **支払い方法の設定を忘れないでください。** どちらも無料枠で始められますが、従量課金を設定していないと上限に達した時点で処理が止まります。
> Gemini の無料枠は 1 分あたり約 10〜15 回の API 呼び出しが上限です。

#### 1. Deepgram（音声を文字にするサービス）

1. [https://console.deepgram.com/](https://console.deepgram.com/) にアクセス
2. アカウントを作成してログイン
3. ダッシュボードの「API Keys」から新しいキーを作成
4. 表示された文字列をコピーして保管

#### 2. Google AI（Gemini）（文字を翻訳するサービス）

1. [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey) にアクセス
2. Google アカウントでログイン
3. 「APIキーを作成」をクリック
4. 表示された文字列をコピーして保管

## セットアップ（最初だけ）

### 前提条件

- Windows 10 / 11
- インターネット接続

**Python を事前にインストールする必要はありません。** 初回起動時に、必要なものが自動でインストールされます。

| 自動で入るもの | 用途 |
|---|---|
| [uv](https://docs.astral.sh/uv/) | Python 3.13 とライブラリを準備するツール（Python 本体もこれが自動で取得します） |
| Python 3.13 + ライブラリ | アプリ本体の実行環境（このフォルダ内の `.venv` に入ります。PC 全体の Python には影響しません） |
| ffmpeg | 動画からの音声抽出・字幕の焼き込み・音声ファイルの変換（マイク翻訳だけなら不要） |

### 手順

1. このフォルダ内の **`launch.bat`** をダブルクリックして起動します
   - 初回だけ、黒い画面でセットアップ（`setup.bat`）が自動で始まります。数分かかるので、完了するまで画面を閉じないでください
   - ffmpeg のインストール時に「このアプリがデバイスに変更を加えることを許可しますか？」と表示されたら「はい」を選んでください
   - 2回目以降はセットアップは行われず、すぐに起動します
2. 初回起動時は自動でブラウザが開きます
   - 開かない場合は [http://localhost:7861](http://localhost:7861) をブラウザで開いてください
3. 画面上部の「API Keys」欄に Deepgram と Google AI のキーを入力します

> タスクトレイ（画面右下）にアイコンが表示されます。右クリックして「終了」を選ぶとアプリが終了します。

### 自動セットアップがうまくいかない場合（手動セットアップ）

会社の PC などで自動インストールが制限されている場合は、以下を順番に行ってください。

#### 1. uv をインストールする

スタートメニューで「PowerShell」と検索して開き、以下を貼り付けて Enter を押します。

```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

> 終わったら PowerShell を一度閉じて開き直し、`uv --version` と入力してバージョンが表示されれば成功です。

#### 2. Python とライブラリを準備する

PowerShell でこのフォルダに移動し、以下を実行します（Python 3.13 も自動でダウンロードされます）。

```
cd "C:\Users\（あなたのユーザー名）\（このフォルダ）"
uv sync --extra microphone
```

#### 3. ffmpeg を手動でインストールする

PowerShell で以下を実行します。

```
winget install --id Gyan.FFmpeg -e
```

`winget` が使えない場合は：

1. [https://www.gyan.dev/ffmpeg/builds/](https://www.gyan.dev/ffmpeg/builds/) から `ffmpeg-release-essentials.zip` をダウンロード
2. ZIP を解凍し、中の `bin` フォルダのパス（例：`C:\ffmpeg\bin`）をコピー
3. スタートメニューで「環境変数」と検索 →「システム環境変数の編集」→「環境変数」→「Path」をダブルクリック →「新規」→ コピーしたパスを貼り付けて OK

> PowerShell を開き直して `ffmpeg -version` と入力し、エラーが出なければ成功です。

これで `launch.bat` から起動できます。

## 使い方

翻訳元の言語・翻訳先の言語・ドメイン（専門分野）は、画面上部で共通に設定します。ドメインに迷ったら `general` を選んでください。

### 動画に字幕を付ける

1. **「🎬 動画字幕」タブ**をクリック
2. 「動画ファイル」欄に動画をドラッグ＆ドロップ
3. **「🎬 字幕を生成する」**ボタンをクリック
4. 処理が終わったら「字幕付き動画」と「SRT ファイル」をダウンロード

**処理の流れ（処理ログで確認できます）：**

```
🎵 音声を抽出中...
📝 文字起こし中（Deepgram）...
🌐 日本語に翻訳中（Gemini）...
🎬 字幕を動画に焼き込み中...
```

| ファイル | 説明 | 使い方 |
|---|---|---|
| 字幕付き動画（MP4） | 日本語字幕が焼き込まれた動画 | そのまま共有・配信に使用 |
| SRT ファイル | 字幕データのみ（動画なし） | YouTube などへの字幕追加に使用 |

SRT ファイルを YouTube で使うには、YouTube Studio で動画をアップロードし、「字幕」タブの「ファイルをアップロード」からダウンロードした `.srt` ファイルを選択します。

### マイクをリアルタイム翻訳する

1. **「🎤 Microphone」タブ**をクリック
2. **「Start」**ボタンをクリック
3. マイクに向かって話す（英語など）
4. 画面下部に文字起こしと翻訳が表示される
5. 終了するときは**「Stop」**をクリック

### 音声ファイルを翻訳する

1. **「📁 Audio File」タブ**をクリック
2. 音声ファイル（WAV・FLAC・MP3 など）をアップロード
3. **「Process File」**ボタンをクリック（中止するときは「Cancel」）

### 辞書を作る

**「📖 辞書」タブ**で、専門用語とその訳語（`dictionary.csv`）を管理します。

- 表で閲覧・検索・編集・保存する（保存前の内容は `dictionary.csv.bak` に退避されます）
- 講義資料（PDF / TXT / MD / SRT / VTT）や貼り付けたテキストから、辞書にない用語の候補を出す
- 直近の翻訳結果から、辞書にあるのに訳文で使われなかった用語と、未登録の用語の候補を確認する
- 候補にチェックを入れて「辞書に追加」で登録する

翻訳に辞書を使うには、`.env` に `DICTIONARY_PATH=dictionary.csv` を書いてアプリを再起動してください。設定されていない場合は、タブに警告が表示されます。

### 所要時間の目安

いずれも 90 秒の音声で 1 回だけ測った値です（2026-10-29）。API の混み具合や動画の長さで変わります。

| 機能 | 実測値 |
|---|---|
| 動画字幕 | 90 秒の動画に 77.1 秒 |
| マイク翻訳（話し終わり → 訳文表示） | 中央値 2.92 秒 / p95 3.95 秒（音声ファイルをマイクと同じ経路に実時間で流した模擬） |

マイク翻訳の遅延は、画面に区間ごとの内訳が表示され、「⏱ 遅延の計測結果をCSVで保存」で保存できます。

## 仕様

| 項目 | 内容 |
|---|---|
| 入力 | マイク音声（ブラウザ）、音声ファイル、動画ファイル |
| 出力 | 文字起こしと訳文の画面表示、TXT、字幕付き動画（MP4）、SRT、遅延計測 CSV |
| 言語 | 英語・日本語・中国語・韓国語・スペイン語・フランス語・ドイツ語（翻訳元・翻訳先とも選択可） |
| ドメイン | `general` / `economics` / `technology` / `medical` / `legal` / `particle_physics` |
| 音声認識 | Deepgram `nova-2-general`（無音 500ms で発話を確定） |
| 辞書 | CSV（`source_term,target_term,notes`）。原語と訳語が同じ行は「そのまま使う」用語として扱う |
| 実行環境 | Windows 10 / 11、Python 3.13（`setup.bat` が自動で準備） |

### 処理の流れ

```
音声 → Deepgram で文字起こし → 文の途中で切れた発話を結合 → Gemini で翻訳 → 画面表示 / 字幕の焼き込み
```

### 機能ごとの設定

| 項目 | マイク翻訳 | 動画字幕 |
|---|---|---|
| 翻訳モデル（既定） | `gemini-2.5-flash` | `gemini-3.8-flash`（CLI は `gemini-2.5-flash`） |
| Thinking | なし（速度優先） | 1024 トークン（精度優先） |
| 発話を結合する上限 | 8 秒 / 30 語 | 20 秒 / 60 語 |
| 翻訳時に参照する文脈 | 直前 5 文 | 直前 5 文 |
| 並列数 | 3 ワーカー | 1 文ずつ順番に翻訳 |

### 実装済みで既定 OFF の機能

検証で十分な効果を確認できていないため、既定では無効にしています。

| 機能 | 環境変数 | 無効にしている理由 |
|---|---|---|
| Deepgram キーワードブースト | `DEEPGRAM_KEYWORD_BOOST_ENABLED` | 一般語が辞書の用語に置き換わる誤認識が増え、5 クリップ平均の chrF が 0.030 低下した |
| Whisper 再検証 | `WHISPER_REVERIFY_ENABLED` | 正しい補正と誤補正を信頼度の閾値だけでは分けられず、CPU 推論で遅延も増える |
| 不自然度チェック | `UNNATURALNESS_CHECK_ENABLED` | 判定の精度は上がったが、翻訳品質の改善は別のクリップで再現しなかった |

設定できる項目の一覧は [.env.example](.env.example) を参照してください。

## 工夫点

### 文の途中で区切らない

音声認識は文の途中で発話を区切ることがあり、そのまま訳すと「米国では。フェデラルと呼ばれています。」のような不自然な訳になります。文末の句読点と LLM の判定で文の切れ目を見分け、続きの発話と結合してから翻訳します。

### リアルタイム性を壊さない

文末判定の LLM には 0.6 秒のタイムアウトを設け、超えたら句読点による判定に切り替えます。翻訳が追いつかずキューがあふれたときは、古い文を捨てて最新の文を優先します。

### 並列に翻訳しても訳語をそろえる

マイク翻訳は 3 つのワーカーで並列に翻訳しますが、文脈を全ワーカーで共有し、同じ単語の訳が揺れないようにしています。

### 専門用語は辞書で支える

用語の訳語に加えて、音声認識の誤りの補正（`TIFINE` → `T5`、`memory war` → メモリウォール など）も登録できます。辞書の作成は「📖 辞書」タブが支援し、資料や翻訳結果から登録すべき用語の候補を提案します。

### 問題にその場で気づけるようにする

翻訳中に次の 3 点を確認します。

- **訳し漏れ：** 訳文が直近の傾向より極端に短い文に「⚠️ 要確認」を付ける
- **用語漏れ：** 辞書の用語が原文にあるのに、指定の訳語が訳文にない場合に検出する
- **利用上限：** Gemini の呼び出し回数が無料枠の上限に近づくと警告する

### 体感に近い形で遅延を測る

「話し終わり → 訳文表示」までを、音声認識・文末判定・Whisper 再検証・翻訳待ち・翻訳 API・画面表示の 6 区間に分けて 1 文ごとに記録します。どこで時間がかかっているかが分かります。

### 数値で確かめてから採用する

人手で確認した正解訳つきのベンチマーク 14 件で設定を比較し、差が偶然でないかはペアードブートストラップ検定で確かめています。

- **モデルの選定：** 動画字幕は COMET-22 が最も高かった `gemini-3.8-flash`（0.930、1 文あたり 2.43 秒）を採用しました。マイク翻訳は 1 文あたりの翻訳が速い `gemini-2.5-flash`（0.920、1.45 秒）を使います
- **採用しなかった例：** `gemini-3.5-flash-lite` は速いものの、COMET-22 が有意に低かったため見送りました（差 -0.0055、p ≈ 0.003、10 ベンチマーク）
- **指標の見直し：** 0.98〜1.0 に張り付いて差が出にくい LLM 判定に頼らず、COMET-22 と chrF で比較しています

検証の詳細は [CHANGELOG.md](CHANGELOG.md) と `experiments/` に記録しています。

### Python がなくても使える

`launch.bat` をダブルクリックするだけで、uv・Python・ライブラリ・ffmpeg が自動で準備されます。ライブラリはこのフォルダ内の `.venv` に入るため、PC 全体の環境には影響しません。

## よくある質問

**Q. 動画をアップロードできない**

アプリを再起動してください（`launch.bat` をダブルクリック）。それでも解決しない場合は、ブラウザのキャッシュをクリアするか、別のブラウザを試してください。

**Q. 「APIキーが未設定です」と表示される**

画面上部の「API Keys」欄に Deepgram と Google AI のキーが入力されているか確認してください。

**Q. 翻訳が途中で止まった**

Gemini のレート制限（1 分あたりの上限）に達した可能性があります。アプリは自動でリトライしますが、エラーが出た場合はしばらく待ってから再試行してください。

**Q. 字幕の日本語が文字化けしている**

Windows の場合は自動で日本語対応フォント（Yu Gothic）が使われます。正しく表示されない場合はお知らせください。

**Q. 処理をキャンセルしたい**

音声ファイルは「📁 Audio File」タブの「Cancel」ボタンで中止できます。動画字幕タブにキャンセルボタンはありません。
